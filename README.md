#  TaskFlow - MERN Task Management Application

TaskFlow is a beginner-friendly full-stack MERN (MongoDB, Express.js, React, and Node.js) task management application. It allows users to securely register, log in, and manage their daily tasks through a clean and responsive interface.

---

## ✨ Features

*  User Authentication (Login & Signup)
*  JWT & Cookie-based Authentication
*  Add New Tasks
*  Update Tasks
*  Delete Tasks
*  View All Tasks
*  Responsive User Interface
*  MongoDB Atlas Integration
*  Frontend Deployment with Vercel
*  Backend Deployment with Render

## Installation

### Clone the repository

```bash
git clone https://github.com/muhammadus9139/TaskFlow-mern.git
cd TaskFlow-mern
```

### Install dependencies

#### Backend

```bash
cd backend
npm install
```

#### Frontend

```bash
cd ../frontend
npm install
```

### Configure Environment Variables

Create a `.env` file inside the **backend** folder.

```env
MONGO_URL=your_mongodb_connection_string
JWT_SECRET=your_secret_key
PORT=5000
```

Create a `.env` file inside the **frontend** folder.

```env
VITE_API_URL=http://localhost:5000
```

---

## Run the Project

### Backend

```bash
cd backend
npm run dev
```

### Frontend

```bash
cd frontend
npm run dev
```
